# Project Scope

Projekt: FirstRealHarnessEvaluation_KarpathiesMD
Datum der Scope-Entscheidung: 2026-05-10
Status: aktiv

## Festgelegter Primärscope
Dieses Repo ist primär ein fokussiertes Hypothesentest-Rig.

## Kernhypothese
Dieses Repo dient primär dazu, die Hypothese zu testen, ob eine minimale Harness-Policy gegenüber einer überladenen Policy messbar besser performt.

## Einordnung von Nebenthemen
Dashboard/Web-UI, Diagramme, GitHub Pages, Zusatzprotokolle und wissenschaftliche Auswertungs-Helfer sind Nebenthemen relativ zur Kernhypothese. Sie sind nur dann scope-gerecht, wenn sie die Durchführung, Auswertung oder belastbare Beantwortung der Kernhypothese direkt verbessern.

## Präzisierung zur UI
Dashboard/Web-UI ist nice-to-have und kein Primärziel des Repos. Es darf als unterstützende Bedien- oder Auswertungsfläche existieren, soll aber nicht als eigenes Produkt oder gleichrangiger Schwerpunkt ausgebaut werden.

## Scope-Regel für nächste Entscheidungen
Neue Arbeit ist nur dann im Primärscope, wenn sie die belastbare Beantwortung der Kernhypothese direkt verbessert.

## Explizit nicht Primärscope
- allgemeine Harness-Evaluationsplattform
- eigenständiges Dashboard-Produkt
- breite Präsentations- oder Visualisierungsarbeit ohne direkten Erkenntnisgewinn
- Infrastruktur-Ausbau ohne klaren Beitrag zur Hypothesenantwort
